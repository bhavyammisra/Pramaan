# scripts/

Helper scripts: synthetic data generation, load/latency testing. One line per script here describing what it does.

- `build_deck.py`: rebuilds the screening deck from the BIOS template (`python scripts/build_deck.py <template.pptx> docs/05-pitch/Pramaan_BIOS_Screening.pptx`).
- `build_deck_v3.py`: v3/v4 deck (icons, `--n8n` for v4).
- `build_deck_v5.py`: v5 deck from the BIOS template (`python scripts/build_deck_v5.py <template.pptx> docs/05-pitch/Pramaan_BIOS_Screening_v5.pptx`).
